# 实时视频生成学习笔记

记录实时视频生成的基础知识、论文阅读、代码理解和复现实验。用自己的话解释方法，区分论文报告、个人理解与实测结果。

- [论文阅读模板](PAPER-TEMPLATE.md)
- [实验记录模板](EXPERIMENT-TEMPLATE.md)

## 学习目标

- 理解视频生成的基本建模方式与推理流程。
- 理解流式生成、低延迟交互、长视频生成之间的联系。
- 研究蒸馏、缓存和推理优化如何影响速度、质量与显存。
- 完成可复现的小实验，积累自己的结论。

## 笔记组织

随着内容增加，逐步创建以下目录：

| 目录 | 内容 |
| --- | --- |
| `foundations/` | 扩散模型、Flow Matching、视频建模基础 |
| `papers/` | 一篇论文一份笔记 |
| `topics/` | 流式生成、蒸馏、缓存、时序一致性等专题 |
| `experiments/` | 实验配置、复现步骤、结果与失败分析 |
| `assets/` | 示意图、截图和小型演示素材 |

## 记录原则

1. 保留论文与代码来源，并记录阅读或实验日期。
2. 区分“论文报告”“我的理解”“实测结果”和“待验证”。
3. 比较速度时同时记录硬件、分辨率、帧数、精度、推理步数与计时范围。
4. 分开记录首帧延迟、持续生成 FPS 和输入变化后的响应延迟；未报告的指标明确标注。
5. 模型权重、数据集和大型视频使用外部链接引用。

## 如何添加笔记

在 GitHub 仓库中选择 **Add file → Create new file**，输入例如 `papers/论文简称.md`，复制对应模板并填写，然后点击 **Commit changes** 保存。最后编辑本首页，添加笔记链接。
